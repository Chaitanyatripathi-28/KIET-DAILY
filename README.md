# 🎓 KIET Daily

### Your Campus. Your News. One Place.

KIET Daily is a student-focused campus information platform designed to make college updates easier to access, discover, and manage.

The platform brings campus news, events, notices, placement opportunities, student achievements, and interactive student features together in one place.

It aims to reduce the need to search through multiple groups and channels for important campus information.

## 🚀 Key Features

- 📰 **Campus News:** Explore the latest campus stories and updates.
- 📢 **Notice Board:** Access important announcements and notices.
- 📅 **Events:** Discover upcoming campus events and activities.
- 💼 **Placement Updates:** Find placement and internship opportunities.
- 🏆 **Student Achievements:** Highlight student accomplishments.
- 🗳️ **Polls:** Participate in campus polls.
- 💬 **Student Voice:** Share ideas and opinions with the campus community.
- 📸 **Campus Gallery:** Explore campus moments and photographs.
- 🔐 **Student Authentication:** Student registration and login with academic profile information.
- 👨‍💻 **Admin Control Center:** Manage stories, events, notices, placements, polls, and student submissions.
- 📱 **Responsive Design:** Access the platform on mobile phones, tablets, and computers.
- 🔖 **Saved Stories:** Keep useful stories for later.

## 🎯 Project Objective

The main objective of KIET Daily is to create a centralized digital campus platform where students can access useful information without depending on multiple unofficial communication channels.

The project focuses on improving campus communication, student participation, and access to academic and extracurricular updates.
